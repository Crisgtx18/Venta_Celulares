# TechCelulares | Catálogo de Venda de Celulares

Página web de catálogo para venda de celulares novos e seminovos. Desenvolvida com HTML, CSS e JavaScript, com design moderno no estilo cyberpunk (preto e ciano), responsivo e com filtros por marca.

---

## Descrição

Este projeto é uma página de catálogo de celulares criada para demonstrar como pequenos negócios podem ter uma presença online profissional. O site permite que o cliente visualize os produtos disponíveis, filtre por marca e entre em contato diretamente pelo WhatsApp.

---

## Seções

- Início: Apresentação da loja com chamada para ação.
- Catálogo: Lista de celulares com imagem, descrição e preço.
- Filtros: Botões para filtrar por marca (iPhone, Samsung, Xiaomi, Motorola).
- Contato: Botões de WhatsApp e Email para atendimento direto.

---

## Tecnologias utilizadas

- HTML5 para a estrutura semântica.
- CSS3 para o design, animações e efeitos neon.
- JavaScript para os filtros de marca.
- Git e GitHub para controle de versão.

---

## Funcionalidades

- Catálogo de produtos com imagem, nome, marca, descrição e preço.
- Filtros por marca com JavaScript puro.
- Botão de consulta por WhatsApp em cada produto, com mensagem pré-escrita.
- Seção de contato com WhatsApp e Email.
- Design responsivo para celular, tablet e computador.
- Efeitos visuais neon e fundo estilo cyberpunk.

## Como usar

1. Clone o repositório:

   git clone https://github.com/Crisgtx18/catalogo-celulares.git

2. Entre na pasta:

   cd catalogo-celulares

3. Abra o arquivo index.html no navegador ou use o Live Server no VS Code.

---

## Personalização

Para adaptar esta página para outro tipo de negócio, basta:

- Trocar os produtos no arquivo index.html.
- Substituir as imagens na pasta assets/pictures/.
- Alterar as cores no arquivo style.css.
- Atualizar o número de WhatsApp nos links.
